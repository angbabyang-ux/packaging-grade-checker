# 화장품 포장재 재질·구조 간이평가

화장품 포장재(용기·라벨·마개·펌프 등)의 **재활용 용이성 등급(최우수/우수/보통/어려움)**을 비전문가도 몇 번의 클릭만으로 가늠해볼 수 있는 사내용 간이 진단 웹페이지입니다.

담당 마케터가 신제품 포장재를 확정하기 전에, 어떤 등급이 예상되는지 빠르게 확인하고 R&D·구매 담당자와 논의할 근거 자료로 쓰기 위해 만들었습니다.

▶ [바로 사용해보기](#) *(GitHub Pages 배포 후 링크 채우기)*

## 이게 뭔가요?

한국은 2019년 「자원의 절약과 재활용촉진에 관한 법률」 개정으로 **포장재 재질·구조 평가 제도**를 시행 중입니다. 재활용의무생산자는 포장재마다 재활용 용이성을 자체평가하고, 그 결과를 한국환경공단에서 확인받아야 합니다. "재활용 어려움" 등급은 포장재 겉면에 표시가 의무입니다.

이 페이지는 그 제도의 판정 로직을 화장품에서 자주 쓰는 포장재 유형(유리병, 페트병, 합성수지 단일용기·트레이, 복합재질 용기·트레이/필름류, 스프레이 금속캔) 위주로 재구성한 **간이 자가진단 도구**입니다.

## ⚠️ 반드시 읽어주세요

- 이 도구는 **사내 참고용**입니다. 법적 효력이 있는 공식 등급은 한국환경공단 평가결과서(iepr.or.kr 신청)로만 확정됩니다.
- 접착제 도포면적, 재질 비중 등 **공인시험기관의 기기분석이 필요한 정량 기준**은 실물 시험 없이는 정확히 알 수 없습니다. 이 도구는 육안으로 확인 가능한 정보를 기준으로 한 근사치입니다.
- 신제품 출시 전에는 반드시 정식 평가를 신청하세요.

## 판정 기준 출처

- 환경부고시 「포장재 재활용 용이성 등급평가 기준」, 「포장재 재질·구조 등급표시 기준」, 「포장재의 재질·구조 기준」
- 환경부 가이드라인 "포장재 재질·구조 평가제도의 이해" (2020.2)
- 2021.1.7 시행 개정사항 (페트병 최우수 등급 확대, 유리병 표면코팅 기준 완화 등)
- 2025.1.7 시행 환경부고시 제2025-2호 개정사항 (최우수 등급 대상을 페트병·PSP 2종에서 유리병·합성수지 단일재질 용기·트레이류를 포함한 4종으로 확대)

세부 근거와 한계점은 페이지 상단의 **"판정 기준 안내"** 버튼에서 확인할 수 있습니다.

## 기술 스택

순수 HTML/CSS/JavaScript로만 작성된 정적 페이지입니다. 빌드 과정이나 서버가 필요 없어 GitHub Pages로 바로 배포할 수 있습니다.

```
index.html   화면 구조
style.css    스타일 (라이트/다크 모드 대응)
data.js      포장재 카테고리별 판정 규칙 데이터
app.js       화면 전환/판정 실행 로직
```

## 규칙 업데이트하기

환경부 고시는 주기적으로 개정됩니다. 규칙을 바꿔야 할 때는 `data.js`의 `CATEGORIES` 객체만 수정하면 됩니다. 각 항목에는 근거 조문을 파악할 수 있도록 파일 상단 주석에 출처를 남겨두었으니, 개정 시 주석도 함께 갱신해주세요.

## 로컬에서 열어보기

별도 설치 없이 `index.html`을 브라우저로 열거나, 정적 서버로 띄우면 됩니다.

```bash
python -m http.server 8000
# http://localhost:8000 접속
```
